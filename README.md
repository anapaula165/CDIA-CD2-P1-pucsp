# CDIA-CD2-P1-pucsp
Explicação de cadernos sobre o que vi em ciência de dados II.

Neste trabalho, apresento a estruturação de um pipeline de Integração Contínua aplicado ao projeto Bella Tavola, que utiliza uma API para detecção de risco em pedidos de restaurante. O foco foi automatizar o ciclo de desenvolvimento, desde os testes básicos até a integração com modelos de Machine Learning
